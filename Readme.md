# Applied Statistics Lab

This project contains a series of Jupyter notebooks for hands-on learning and experimentation with core concepts in applied statistics. The labs cover topics such as probability distributions, descriptive statistics, hypothesis testing, inference estimators, maximum likelihood estimation, model fitting, non-parametric estimation, and binary classification.

## Structure

- `Random Variables.ipynb`: Experiments with discrete and continuous random variables, histograms, binomial and exponential distributions, and the central limit theorem.
- `Maximum Likelihood Estimation.ipynb`: Exercises on likelihood functions, optimization, and parameter estimation for various distributions.
- `requirement.txt`: List of required Python packages.

## Getting Started

1. **Install dependencies**  
   Run the following command to install required packages:
   ```sh
   pip install -r requirement.txt
   ```

2. **Open notebooks**  
   Use [Visual Studio Code](https://code.visualstudio.com/) or [Jupyter Notebook](https://jupyter.org/) to open and run the `.ipynb` files.

## Requirements

- Python 3.8+
- Jupyter Notebook or VS Code with Python extension

### Python Packages

- numpy
- pandas
- matplotlib
- seaborn
- scipy
- scikit-learn
- statsmodels

(See [`requirement.txt`](requirement.txt) for details.)

## Usage

Each notebook is self-contained and includes explanations, code cells, and exercises. Run the cells sequentially and follow the instructions to complete the lab exercises.
